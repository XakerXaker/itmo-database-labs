# itmo-database-labs

Решения заданий для самостоятельной работы из учебно-методического пособия
В.В. Повышева [«Базы данных. Практикум»](https://drive.google.com/file/d/19G2stMCwIEx5piQ4N8H5EVEUpIkx5bbR/view) (Университет ИТМО, 2020). Практикум посвящён
написанию запросов `SELECT` и состоит из шести последовательных практических работ.

**Диалект SQL:** T-SQL (Microsoft SQL Server). Запросы рассчитаны на учебную базу данных
[AdventureWorks](https://learn.microsoft.com/sql/samples/adventureworks-install-configure).

## Структура

| Папка  | Тема                                              |
|--------|---------------------------------------------------|
| `lab1` | SELECT, WHERE, ORDER BY                           |
| `lab2` | GROUP BY                                          |
| `lab3` | Выборка из нескольких таблиц (JOIN)               |
| `lab4` | Подзапросы                                        |
| `lab5` | Запросы как источник данных, ОТВ                  |
| `lab6` | Оконные функции, OVER                             |

В каждой папке:

- `tasks.md` – условия заданий в текстовом виде;
- `solutions.sql` – решения, пронумерованные так же, как задания.
